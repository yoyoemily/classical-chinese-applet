## 工作方式

**先审后修**：逐字过 9 点检查，只记录问题不修复。全部过完后按问题类型归类，同类型统一修复。

### 问题记录格式

每个发现的问题按以下格式记录：

```
| quizItem ID | 字 | 检查点 | 严重度 | 问题描述 | 建议修复 |
```

| 严重度 | 含义 |
|:--:|------|
| 🔴 | 答案错误/数据事故，影响答题正确性 |
| 🟡 | 格式问题/不够规范，不影响答题 |
| 🟢 | 建议优化，不影响功能 |

### 批量修复分组

全部审核完成后，按问题类型分组修复：

| 组 | 检查点 | 修复方式 | 涉及数据 |
|----|--------|---------|---------|
| A | #3 正确答案有误 | 改 quizItem.definition + article_keyword 同步 | 词书 JSON + articles JSON |
| B | #4 选项重复 / #5 干扰项含正确答案 | 改 distractors | 词书 JSON |
| C | #6 sentenceText 不完整 | 改 sentenceText，参考 articles JSON 原文 | 词书 JSON |
| D | #7 targetWord 不一致 | 改 quizItem.targetWord | 词书 JSON |
| E | #8 kidRef 指向错误 | 改 kidRef 或新增/修正 article_keyword | 词书 JSON ± articles JSON |
| F | #9 非壳文章缺句子 | 在 articles JSON 补句子 + keyWord | articles JSON |
| G | #1 出处错误 / #2 译文错误 | 修 sentenceSource / sentenceTranslation | 词书 JSON |

> 逐本词书、逐字词过 9 点检查，先记录问题不修复。当前进度：**0/546 字**。

### 审核流程（9 点检查）

轮到某字时，从数据库提取该字全部 quizItem（例句、译文、出处、4 个选项，标注正确选项），逐项检查：

1. **例句出处是否正确**
2. **例句译文是否正确**
3. **正确答案是否有误** → [[quiz-item-definition-fix]]
4. **选项之间是否重复**（完全重复、包含性重复、近义重复）→ [[quiz-item-definition-fix]]
5. **干扰项是否包含正确答案**（选了就判错，数据事故）→ [[quiz-item-definition-fix]]
6. **sentenceText 是否完整可读**（断句截断、多字少字、混入标点/序号/语法说明）→ [[quiz-item-definition-fix]]
7. **targetWord 与 entry.character 是否一致**（是否有张冠李戴）→ [[quiz-item-definition-fix]]
8. **kidRef 指向是否正确** → [[quiz-item-definition-fix]] 或 [[article-keyword-correction]]
9. **出处若是非壳文章，该例句句子是否缺失** → [[article-adjustment-workflow]]

### 数据提取 SQL

```sql
SELECT qi.id, qi.target_word, qi.definition, qi.sentence_text, qi.sentence_translation, qi.sentence_source, qi.kid_ref,
       qd.label as distractor
FROM quiz_item qi
JOIN word_book_entry wbe ON wbe.id = qi.entry_id
LEFT JOIN quiz_distractor qd ON qd.quiz_item_id = qi.id
WHERE wbe.id = '<entry_id>'
ORDER BY qi.id, qd.sort_order;
```

### 审核状态标记

| 标记 | 含义 |
|:--:|------|
| ⬜ | 待审核 |
| ✅ | 审核通过，无问题 |
| 🔧 | 有问题，已修复 |
| ⚠️ | 有问题，需确认后再修 |
| ⏭️ | 跳过（如 0 题） |
